## Dashboard

Your financial snapshot at a glance.

### Dashboard Features

- **Morning Briefing**: Quick summary of your financial status
  - Current net worth
  - Income received this month
  - Expenses incurred
  - Savings rate

- **Key Metrics**:
  - Net Worth (liquid balance)
  - Total Income
  - Total Expenses
  - Cash Flow
  - Savings Balance
  - Investment Value

- **Recent Transactions**: Last 10 financial movements

- **Financial Goals**: Progress towards your targets

- **Monthly Overview**: Charts and trends for current month

### Interpreting Dashboard Data

- **Net Worth** = Sum of all account balances
- **Savings Rate** = (Income - Expenses) / Income × 100%
- **Cash Flow** = Income - Expenses
- ⚠️ **Warning**: Displays if monthly expenses exceed income

## Managing Accounts

Accounts represent your financial containers (bank accounts, wallets, investment portfolios, etc.)

### Creating an Account

1. Go to **Accounts** section
2. Click **+ New Account**
3. Fill in account details:
   - **Account Name**: e.g., "HDFC Savings"
   - **Account Type**: Choose from:
     - Income (salary accounts)
     - Expense (credit cards, spending accounts)
     - Savings (savings accounts)
   - **Account Subtype**: Customize category
   - **Initial Balance**: Starting amount (can be 0)
   - **Currency**: INR (default)
4. Click **Create Account**

### Account Types Explained

- **Income Accounts**: Where money comes IN
  - Salary account
  - Freelance income
  - Bonus/Investment returns

- **Expense Accounts**: Where money goes OUT
  - Credit cards
  - Cash wallets
  - Shopping wallets

- **Savings Accounts**: Where money is STORED
  - Bank savings accounts
  - Fixed deposits
  - Emergency funds

### Managing Accounts

- **View Balance**: Click account to see details and transaction history
- **Edit Account**: Update name, type, or balance
- **Delete Account**: Remove account (only if empty)
- **Transaction History**: See all movements in/out

## Tracking Transactions

Every money movement is a transaction.

### Creating a Transaction

Go to **Transactions** → Click **+ New Money Flow**

#### Step 1: Select Flow Type

Choose transaction type:

- **💰 Expense**: Money going out
- **📈 Income**: Money coming in
- **➡️ Transfer**: Money between your accounts
- **💾 Savings**: Money to savings (investment)
- **🤑 Salary**: Salary income (special type)

#### Step 2: Enter Transaction Details

**For Expenses:**

- Amount (required)
- Date (click calendar to select)
- Payment Method (UPI, Cash, Card, etc.)
- Source Account (where money comes from)
- Category (Food, Rent, Utilities, etc.)
- Description (optional notes)

**For Income:**

- Amount (required)
- Date (click calendar to select)
- Destination Account (where money goes)
- Category (Salary, Freelance, etc.)
- Description (optional notes)

**For Transfers:**

- Amount (required)
- Date (click calendar to select)
- Source Account (from which account)
- Destination Account (to which account)
- Description (optional notes)

**For Salary Income:**

- Amount (gross salary)
- Date
- Destination Account
- Net Take Home
- Employee PF (if deducted)
- Salary Month (auto-filled from date)

#### Step 3: Submit

Click **Add Transaction** to save.

### Managing Transactions

- **View Details**: Click any transaction row to see full details
- **Edit Transaction**: Modify amount, date, or accounts
- **Delete Transaction**: Remove transaction (careful - affects balances!)
- **Filter**: By account, category, date range
- **Search**: Find transactions by description or amount

### Transaction Best Practices

✓ **Log daily**: Better accuracy than weekly
✓ **Use categories**: Helps with budget tracking
✓ **Add descriptions**: Useful for future reference
✓ **Keep receipts**: For large transactions
✓ **Review monthly**: Catch errors early

## Managing Investments

Track your investment portfolio across various instruments.

### Investment Types Supported

**Fixed Return Instruments:**

- Fixed Deposit (FD)
- Recurring Deposit (RD)
- Bonds & Debentures

**Market-Linked:**

- Mutual Funds
- Direct Stocks/Equity
- ETFs (Exchange Traded Funds)

**Government Schemes:**

- Public Provident Fund (PPF)
- National Pension System (NPS)
- Employees' Provident Fund (EPF)

### Adding an Investment

Go to **Investments** → Click **+ New Investment**

#### Basic Information

- **Investment Name**: e.g., "Mirae Asset Large Cap Fund"
- **Investment Type**: Select from list above
- **Principal Amount**: Initial investment
- **Current Value**: Current market/ledger value
- **Date Opened**: When investment was created
- **Owner**: Myself / Family member
- **Provider**: Bank/Fund house
- **Platform**: Where it's held (e.g., Kuvera, Direct)

#### Additional Details (varies by type)

**For Fixed Deposit:**

- Interest Rate (%)
- Maturity Date
- Maturity Amount (auto-calculated if interest rate provided)

**For Mutual Funds:**

- Units Held
- Cost Basis (average cost per unit)
- Current NAV
- Folio Number

**For Stocks:**

- Number of Shares
- Average Cost Per Share
- Current Price Per Share

**For PPF/NPS:**

- Account Number
- Interest Rate
- Maturity Date

### Tracking Investment Performance

- **Gains/Losses**: Current Value - Principal
- **Gain %**: (Gains / Principal) × 100
- **XIRR**: Internal Rate of Return (calculated)
- **Dashboard**: See total portfolio value

### Managing Investments

- **Update Value**: Keep current values updated regularly
- **Add Events**: Log dividends, reinvestments, etc.
- **Mature Investment**: Mark as closed when matured
- **View Summary**: Total portfolio across all instruments

### Investment Tips

✓ **Update quarterly**: Track market value changes
✓ **Monitor maturity dates**: Don't forget redemptions
✓ **Log all events**: Dividends, interest, reinvestments
✓ **Use folio numbers**: For easy identification
✓ **Review annually**: Rebalance if needed

## Setting Financial Goals

Define and track your financial targets.

### Creating a Goal

Go to **Goals** → Click **+ New Goal**

**Goal Details:**

- **Goal Name**: e.g., "Buy Car", "Vacation Fund"
- **Target Amount**: How much you need (in INR)
- **Target Date**: When you want to achieve it
- **Priority**: Low / Medium / High
- **Current Progress**: Automatically calculated

### Goal Allocation

Allocate funds to goals using:

**Allocation Types:**

1. **Account Allocation**: Link savings account to goal
   - Money saved in that account counts toward goal
   - Example: "House Fund Account" → House Goal

2. **Investment Allocation**: Use investment returns
   - Investment gains count toward goal
   - Example: Mutual fund profits → Retirement Goal

### Tracking Goal Progress

- **Progress Bar**: Visual indicator of progress
- **Current Amount**: Total allocated to goal
- **Remaining**: Amount still needed
- **Target Date**: Countdown to deadline
- **On Track?**: System shows if you're on pace

### Goal Types & Examples

**Short-term (< 1 year):**

- Vacation fund
- Festival expenses
- Gadget purchase

**Medium-term (1-5 years):**

- Car purchase
- Wedding expenses
- Home renovation

**Long-term (> 5 years):**

- House down payment
- Retirement fund
- Education fund

### Goal Tips

✓ **Be specific**: "Save ₹10,00,000 by Dec 2027"
✓ **Allocate funds**: Link accounts/investments to goals
✓ **Review quarterly**: Adjust targets if needed
✓ **Celebrate milestones**: When you hit 50%, 75%, 100%
✓ **Multiple goals**: No limit - save for everything!

## Creating Budgets

Plan and control your monthly spending.

### Creating a Budget

Go to **Budgets** → Click **+ New Budget**

**Budget Details:**

- **Month**: Select month to budget for
- **Category**: Expense category
- **Monthly Limit**: Max amount for this category
- **Expense Nature**:
  - Fixed (same every month - rent, insurance)
  - Dynamic (varies - food, entertainment)

### Common Budget Categories

- 🍽️ Food & Dining
- 🏠 Rent & Home
- 💡 Utilities
- 🛍️ Shopping
- 🚗 Travel & Transport
- 🎬 Entertainment
- 🏥 Medical & Health
- 📚 Education
- 💼 Professional/Work
- 🎁 Gifts & Donations
- 📱 Subscriptions

### Budget Monitoring

**On Dashboard:**

- Budget vs Actual spending
- Over/Under budget indicators
- Visual progress bars
- Category breakdown

**Color Coding:**

## Scheduling Recurring Payments

Automate regular transactions (salary, bills, SIPs, etc.)

### Creating a Schedule

Go to **Schedules** → Click **+ New Schedule**

### Step 1: Basic Information

- **Schedule Name**: e.g., "Broadband Bill"
- **Amount (INR)**: Transaction amount
- **Flow Type**: Expense / Income / Transfer / Savings
- **First Execution Date**: When to start (use calendar picker)

### Step 2: Set Frequency (Dynamic Selection)

#### Daily

- Simple one-click selection

#### Weekly

- **Select Day**: Choose from Sun-Sat buttons
- **Example**: "Every Monday" for weekly gym class

#### Monthly

- **Select Day of Month**: Pick 1-31
- **Example**: "Monthly on 5th" for salary on 5th

#### Quarterly

- **Select Day of Month**: Pick 1-31
- **Example**: "Quarterly on 15th" for quarterly payments

#### Yearly

- **Select Month**: January-December dropdown
- **Select Day**: Pick 1-31
- **Example**: "Annually on Dec 25" for annual subscription

### Step 3: Transaction Details

**For Expenses:**

- Source Account: Where money comes from
- Category: Type of expense
- Notes: Description

**For Income:**

- Destination Account: Where money goes
- Category: Type of income
- Notes: Description

**For Transfers/Savings:**

- Source Account
- Destination Account
- Notes

### Step 4: Create Schedule

Click **Create Schedule** to save.

### Managing Schedules

**Suggested Transactions:**

- Before execution, schedule shows in "Suggested" section
- Review and click **Approve** to confirm
- Click **Skip** to skip one occurrence
- System auto-approves if not manually rejected

**Active Schedules:**

- **View All**: See all created schedules
- **Pause Schedule**: Temporarily stop (click pause icon)
- **Resume Schedule**: Restart paused schedule (click play icon)
- **Delete Schedule**: Remove permanently
- **Frequency Display**: Shows when it runs (e.g., "Monthly on 5th")

### Schedule Examples

**Income Schedules:**

- Salary: Monthly on 1st
- Freelance: Bi-weekly on Monday
- Bonus: Annually on March 31st

**Expense Schedules:**

- Broadband: Monthly on 15th
- Gym: Monthly on 1st
- Insurance: Quarterly on 10th

**Investment Schedules:**

- SIP (Mutual Fund): Monthly on 1st
- PPF: Monthly on 15th
- Recurring Deposit: Monthly on 25th

**Bills:**

- Electricity: Monthly on 10th
- Water: Monthly on 5th
- Mobile: Monthly on 20th

## People Ledger

Track money you lent or borrowed from friends/family.

### Recording a Loan

Go to **People Ledger** → Click **+ New Entry**

**Details:**

- **Person Name**: Who lent/borrowed
- **Amount**: How much
- **Transaction Date**: When it happened
- **Type**:
  - "I gave" (you lent)
  - "I received" (they lent you)
- **Description**: Why/what for
- **Status**: Pending / Settled

### Managing Entries

- **Track Balance**: How much each person owes
- **Mark Settled**: When repaid
- **View History**: All transactions with person
- **Add Repayments**: Record partial/full repayments

### People Ledger Tips

✓ **Record immediately**: Don't rely on memory
✓ **Include reason**: Context helps settlement
✓ **Update status**: Mark as settled when repaid
✓ **Be fair**: Track both ways (borrowing and lending)

## Loans & Dues

Manage personal loans, car loans, home loans, etc.

### Adding a Loan

Go to **Loans & Dues** → Click **+ New Loan**

**Loan Details:**

- **Loan Name**: e.g., "HDFC Home Loan"
- **Lender**: Bank/Institution name
- **Loan Type**: Personal / Home / Auto / Education / Credit Card
- **Loan Amount**: Total borrowed
- **Interest Rate**: Annual %
- **Tenure**: In months/years
- **Start Date**: When loan was taken
- **Due Date**: Maturity date

### Tracking Loan Progress

- **Outstanding Balance**: How much remains
- **EMI Amount**: Calculated monthly payment
- **Interest Paid**: Total interest so far
- **Principal Paid**: Amount repaid
- **Remaining Tenure**: Months/years left

### Recording EMI/Repayments

1. Create monthly schedule for EMI
2. Link to loan account
3. System auto-calculates interest/principal split
4. Track outstanding balance

### Loan Tips

✓ **Compare interest rates**: When choosing lender
✓ **Track EMIs**: Don't miss payments
✓ **Pre-pay if possible**: Reduce interest burden
✓ **Review annually**: Check loan terms and balance
✓ **Set alerts**: For EMI due dates

## Troubleshooting

### Transaction Issues

**Q: Wrong amount recorded**

- Go to transaction, click edit, correct amount
- Balance will auto-adjust

**Q: Missing transaction**

- Check account filters
- Search by date or amount
- Use transaction history view

**Q: Deleted transaction by mistake**

- Check audit log for history
- Contact support for recovery

### Account Issues

**Q: Wrong balance**

- Check all transactions
- Look for duplicate entries
- Verify starting balance

**Q: Can't delete account**

- Must be empty (zero balance)
- Move funds to another account first
- Then delete

### Investment Issues

**Q: NAV not updating**

- Click account, edit
- Enter new current value
- System auto-calculates gains

**Q: Maturity date passed**

- Mark investment as closed
- Create new instrument for reinvestment

### Goal Issues

**Q: Goal not progressing**

- Allocate funds/investments
- Check linked accounts
- Update account balances

**Q: Wrong target date**

- Edit goal and update date
- System recalculates progress
